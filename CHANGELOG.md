# Changelog

All notable changes to the MindMate project will be documented in this file.

## [v1.0.0] - 2025-04-14

### Added
- Initial 4 pages (Main, Chat, Login, Professional Help)
- Claude-style Chat UI with anonymous toggle
- Therapist cards for Dehradun
- Supabase integration for authentication and database
- OpenRouter API integration for AI chat functionality
- Dark theme with cool blue primary color

### Changed
- Navbar layout with Login Icon
- Optional login via Supabase
- Color hover effect from blue to purple
- Anonymous mode toggle for chat sessions

### Technical
- Next.js + Tailwind CSS via ShadCN UI
- Optimized for laptop resolution (1024px+)
- Supabase Auth for user management
- Smooth transitions for UI elements
